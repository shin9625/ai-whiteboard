# 修正内容の確認 (Walkthrough): チャットUI、成果物プレビュー、完全無料AIモデルの追加

WHITEBOARDのタスク詳細を「付箋」から「チャットアプリ形式の対話UI」に刷新し、
「〇〇を作って」という指示に対して、実際に動作するWebアプリ（HTMLプレビュー）やコードファイルが自動生成される機能を実装しました。
さらに、1日14,400回無料で超高速な **Groq（Llama 3.3 70B）** を追加し、Render無料枠再起動時の**スマートリカバリー（自動復元）**も完備しました。

---

## 1. 実装した新機能

### ① チャットアプリ形式の対話スレッド (`TaskChatThread.tsx`)
* **吹き出しタイムライン**:
  * 人間のメッセージは右寄せ（青グラデーション・「あなた」）、AIのメッセージは左寄せ（白/スレート・ロボットアイコン付き）。
  * 会話の文脈（マルチターン対話）がひと目でわかり、スムーズに共同作業が可能。
* **入力フォーム**:
  * Enterキーで即座に送信（Shift+Enterで改行）。
  * 送信時に「Gemini 3.6 Flash (無料)」または「Groq Llama 3.3 (超高速・無料)」を選択可能。
  * AI思考中アニメーション（波打つバッジとスピナー）を搭載。

### ② 成果物（動的Webアプリ & コード）プレビュー (`TaskDetailDrawer.tsx`)
* **「HTMLプレビュー」タブ**:
  * 「〇〇を作って（例: Markdownエディタを作って）」と依頼すると、AIがブラウザ上で動く完全なシングルファイルWebアプリ（Tailwind CSS等のCDN内蔵）を生成。
  * サンドボックス `iframe` で**その場で実際に文字入力やボタン操作ができる動的プレビュー**を実装。
  * 「全画面で開く（別ウィンドウ）」および「HTMLコードをコピー」ボタン付き。
* **「コード / ファイル」タブ**:
  * 生成されたプログラムファイル一覧（例: `editor.html`, `App.tsx` 等）をタブ切り替えで表示。
  * ダークテーマのコードビューワー、コードコピー、ファイルダウンロード機能を完備。

### ③ 完全無料・日常使いモデルの追加: Groq (Llama 3.3 70B Versatile)
* **超高速レスポンス（秒速300トークン）**:
  * Metaの最新フラッグシップモデル `llama-3.3-70b-versatile` を OpenAI 互換 API 経由で呼び出す軽量クライアント（`groqAgent.ts`）を実装。
  * 無料枠で **1日 14,400回（1分 30回）** まで利用可能。
  * `GROQ_API_KEY` を環境変数に追加するだけで、チャット入力欄からワンクリックで切り替えて利用可能。未設定時は安定の `Gemini 3.6 Flash` が自動選択されます。

### ④ Render再起動対策（スマートリカバリー）
* **データ消失ゼロ**:
  * Renderの15分停止・スピンダウンによるサーバー再起動時、タスクが空（0件）であることを検知すると、ブラウザのローカルストレージに自動ミラーリングされた最新バックアップから**自動で全タスク・チャット履歴を復元**します。
  * これにより、Render無料枠でもタスクや成果物が消えなくなりました。

### ⑤ Gemini モデル解決の堅牢化 & プロバイダー相互フォールバック
* **音声/非テキストモデルの完全排除**:
  * Google APIが返すモデル一覧から `tts`, `audio`, `image`, `embedding` 等の非テキストモデルを除外。
  * エラーメッセージからモデルを自動検出する際も、テキスト生成非対応モデルをスキップ。
* **相互フォールバック（Cross-Provider Fallback）**:
  * 片方のモデル（Gemini または Groq）で一時的なレートリミットやエラーが発生した場合、もう片方のプロバイダーへ自動でフェイルオーバーし、タスクの実行と成果物生成を停止させません。
