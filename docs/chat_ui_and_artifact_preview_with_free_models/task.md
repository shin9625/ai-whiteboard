# タスクリスト: チャット型対話UI、成果物プレビュー、完全無料AIモデルの追加

## 概要
WHITEBOARDのタスク詳細を「付箋」から「チャットアプリ形式の対話UI」に刷新し、
「〇〇を作って」という依頼に対してAIがHTMLアプリやコードファイルを自動生成して「HTML」「ファイル」タブでプレビュー・ダウンロードできるようにします。
また、完全無料で超高速な Groq（Llama 3.3 70B）を追加し、Render無料枠再起動時の自動復元（データ消失防止）を実装します。
