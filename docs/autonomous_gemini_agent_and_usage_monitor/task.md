# タスクリスト: Gemini自律エージェント機能 & モデル利用状況モニタリング画面

## 概要
WHITEBOARDのカンバンにタスクが追加された際、Gemini 1.5 Flash がバックグラウンドで自動的に思考・分析・付箋メモの書き込み・レーン移動を行う自律エージェント機能を実装する。
また、ユーザーがいつでもAIの利用状況（本日のリクエスト回数、無料枠残量、トークン数、推定コスト、実行ログ）を画面上で確認できるモニタリングダッシュボードを新設する。

## タスク一覧
- [ ] 1. バックエンド: モデル利用状況テーブル (`model_usage`) のSQLiteスキーマ作成 (`server/src/db/database.ts`)
- [ ] 2. バックエンド: Gemini自律エージェント処理サービスの実装 (`server/src/services/geminiAgent.ts`)
  - [ ] Google AI Studio API を直接呼び出す軽量クライアント（追加の重量パッケージ不要）
  - [ ] タスク自動分析・付箋メモ生成・自動レーン移動ロジック
  - [ ] 実行ごとのトークン消費量・コスト計算・履歴保存
- [ ] 3. バックエンド: APIエンドポイントの新設 (`server/src/api/routes.ts`)
  - [ ] `GET /api/agent/usage`: 利用状況メトリクス取得
  - [ ] `POST /api/agent/trigger/:id`: 即時実行トリガー
  - [ ] タスク作成・移動時の自動発火フック (`waiting_agent` または `assignee: agent`)
- [ ] 4. フロントエンド: モデル利用状況モーダル (`AgentUsageModal.tsx`) の作成
  - [ ] 無料枠メーター (本日 x / 1,500回, パーセンテージ表示)
  - [ ] トークン数 & 推定コスト (円 / USD)
  - [ ] 直近のAI作業ログ一覧
- [ ] 5. フロントエンド: ヘッダーおよびタスク詳細画面へのUI組み込み
  - [ ] ヘッダーに「AI利用状況」バッジ & モーダル起動ボタン
  - [ ] タスク詳細ドロワーに「Geminiで自動実行」ボタン
- [ ] 6. ビルド検証・テスト・Gitコミット & Render自動デプロイ
